# Customer Lifetime Value (CLTV) Prediction

## 🚀 Overview
Built a machine learning model to predict Customer Lifetime Value using real-world insurance data.

## 🏆 Achievement
- Ranked #38 in ML Hackathon

## 🧠 Approach
- Data preprocessing and missing value handling
- Feature engineering (ratios, transformations)
- Models used:
  - LightGBM
  - XGBoost
- Ensemble learning for better performance

## 📊 Evaluation
- R² Score used for evaluation

## 🔧 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- LightGBM, XGBoost

- Importance of feature engineering
- Handling real-world noisy data
